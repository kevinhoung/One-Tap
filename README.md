# SunTap Solar demo (OneTap)

This is a single-file vanilla HTML prototype that looks up roof solar potential via Google Geocoding and the Google Solar API (`buildingInsights:findClosest`). Use Demo mode (or open with `?demo=1`) to explore with sample data and no API calls. Open `index.html` in a browser, paste a Google Maps API key with Geocoding API and Solar API enabled (or pass `?key=`), and never commit a key.
